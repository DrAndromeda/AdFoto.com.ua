### Команда для полного зеркала
```bash
wget --mirror \
     --warc-file=adfoto_complete \
     --page-requisites \
     --adjust-extension \
     --span-hosts \
     --convert-links \
     --restrict-file-names=windows \
     --domains=adfoto.com.ua,web.archive.org \
     --wait=2 \
     --random-wait \
```
